# 🏛️ AITIP 상생 플랫폼 마스터 기본설계서 (Master Architecture Specification)

> **문서 번호**: AITIP-ARCH-MASTER-2026-V06 (최종 완성판)  
> **기준 일시**: 2026-11-08  
> **설계 핵심 원칙**:  
> 1. 가맹점 무설정(비용 0원, 443 아웃바운드 터널) 환경 기준  
> 2. 내부 중추망(Internal MQTT/WSS)과 외부 4대 관문(`adapters/`)의 엄격한 경계선 확립  
> 3. 하드웨어 정합성 사수: **Dual RJ-9 수화기 무전원 DPDT 기계식 바이패스** & **Dual RJ-11 Si3050 DAA 아날로그 CTI** (통신사/키폰 무관 10초 플러그앤플레이)  
> 4. 소상공인 O2O 코어(90%) + 하나로마트 온라인판매 위탁 & 일자리 기관(시니어클럽) 총괄 관리 복지 생태계  
> 5. D1 Outbox (`print_jobs`) 1차 방어선 + 서버 2중 타이머(A/B) 및 1분 `escalation-sweeper` 2차 안전망  
> 6. 점주 수락 시 주방 전표 인쇄(식자재 낭비 방지) 및 주문 유형별 차등 SLA 적용  
> 7. 손님 결제금액 위변조 해킹 차단(점주는 자유롭게 가격 수정 가능) & 외부 AI(A2A) 주문 수신 관문

## 👥 2. 4자 상생 모델 타당성 검증 (경로당-마트-일자리기관-어르신)

복지사업 영역은 현실 상거래의 **"온라인 판매 및 배송 위탁 계약"**을 기반으로 구동됩니다.

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│               경로당 식자재 발주 ➔ 마트 위탁 ➔ 일자리 기관 총괄 관리 메커니즘         │
└────────────────────────────────────────────────────────────────────────────────────────┘

 [1. 경로당 (발주 수요처)]
    • 경로당 회장님/조리사가 단말기 터치(또는 전용 ARS)로 주간 식자재 주문서 발주
    • 예: "쌀 20kg 2포, 배추 5포기, 두부 10모, 돼지고기 5kg" (order_type = FOOD_SUPPLY)
                            │
                            ▼ (클라우드 플랫폼 자동 매핑)
 [2. 단위농협 하나로마트 (물품 공급처 / 위탁자)]
    • 오프라인 매장 장사만 하던 하나로마트는 온라인 판매와 배송 인력이 없음
    • 플랫폼을 통해 관내 일자리 기관에 [온라인 판매 대행 및 배송 위탁]을 공식 위임
                            │
                            ▼ (위탁 판매 및 배송 수탁)
 [3. 일자리 기관 (시니어클럽 등 / 수탁 총괄 관리자)]
    • 일자리 기관 관리 콘솔에 "오늘 관내 경로당 10곳 발주서 묶음" 인입
    • 담당 사회복지사가 매장에 출근한 어르신 사업단에 피킹 지시서 발행 및 2인 1조 배송팀 배정
                            │
                            ▼ (현장 장보기 & 패키징)
 [4. 어르신 일자리 사업단 (현장 수행 주체)]
    • [마트 매대]: 카트를 밀며 신선 채소, 고기, 쌀 피킹 & 박스 패키징
    • [매대 품절 시]: 현장에서 품목 결품 체크 ➔ 기관 담당자 확인 후 부분 취소/대체
                            │
                            ▼ (안전 가택 배송)
 [5. 경로당 주방 직접 배달 & 입고 전자 검수]
    • 어르신 2인 1조가 경로당 주방으로 직접 안전 배송
    • 조리사님이 식자재 상태 확인 후 단말기/모바일 전자서명 (검수 완료)
                            │
                            ▼ (월말/격주 마감)
 [6. 3자 정산 대사]
    • 경로당: 지자체 보조금 카드로 결제 또는 월말 보조금 집행
    • 일자리 기관: 하나로마트 물품 원가와 사업단 위탁 운영·배송 수수료를 투명하게 분리 대사
```

## 📡 5. 현장 환경 중심의 통신 & 3중 안전망 설계 타당성

1. **가맹점 비용 0원 & 포트 443 무설정 (Outbound Only)**:
   - 추가 LTE 회선 가입 불필요. 단말기는 표준 **443 포트(HTTPS/WSS)** 아웃바운드만 열어 공유기 방화벽을 100% 무사 통과.
   - 30초 주기 초경량 핑(Ping)으로 공유기의 유휴(Idle) NAT 세션 강제 종료 차단.
2. **3중 주문 방어선 (Triple Safety Net)**:
   - **1차 (D1 Outbox 영속화 `print_jobs`)**: 주문 생성과 동시에 `orders`와 `print_jobs`에 원자적(D1 `batch`) 저장. 단말기 단선/재부팅 시 미출력 잡 일괄 동기화. 단말 로컬 SQLite 멱등 저장소로 중복 인쇄 차단.
   - **2차 (서버 2중 타이머 에스컬레이션)**:
     - **타이머 A (기기 전달, 30초)**: 인쇄 ACK 미도착 시 ➔ "용지 부족/기기 이상" 판단, 점주 폰 알림.
     - **타이머 B (점주 수락, 60초)**: 점주가 수락 버튼을 안 누르면 ➔ 점주 폰 2차 촉구 알림.
     - **1분 주기 스위퍼 Cron (`escalation-sweeper`)**: DO 알람 유실 시에도 D1을 직접 스캔하여 에스컬레이션을 강제하는 최종 안전망.
   - **3차 (차등 자동 취소 및 환불 Outbox)**:
     - 일반 식당 배달: 5분 최종 무응답 시 자동 취소 및 `refund_jobs` 적재 (PG 자동 환불).
     - 하나로마트 B2B 발주: 5분 취소를 적용하지 않고 당일 마감 시각(`order_cutoff_time`)까지 유지하는 **별도 발주형 SLA** 적용.
3. **수락 시점 전표 인쇄 (식자재 낭비 원천 차단)**:
   - 인입 시에는 단말기 알림음/팝업(`NEW_ORDER_ALERT`)만 작동.
   - 점주가 조리시간을 확인하고 **[수락]을 눌렀을 때 비로소 `KITCHEN_TICKET`과 `RECEIPT` 전표를 자동 인쇄**하여 미수락 취소 시의 식자재 낭비를 막음.
4. **손님 결제금액 위변조 해킹 차단 (Tamper-Proof Payment)**:
   - 가맹점주님은 언제든 메뉴판 가격을 자유롭게 수정할 수 있으며, 주문이 들어올 때 손님이 임의로 가격을 깎아서 결제하지 못하도록 점주님이 등록해 둔 매장 정가표를 기준으로 서버가 결제금액을 안전하게 계산.

## 🤖 6. AI Agent-to-Agent (A2A) 주문 접수 게이트웨이

미래의 상거래는 사람이 직접 앱을 터치하는 것뿐만 아니라, **소비자의 외부 AI 비서가 우리 단말기/서버와 기계 대 기계(A2A)로 대화하며 주문하는 환경**을 수용합니다:

1. **외부 AI 매장/메뉴 실시간 탐색 (`GET /api/v1/agent/discovery`)**:
   - 외부 AI(Gemini, Clova, Siri 등)가 "서초동 된장찌개 맛집"의 영업 상태, 메뉴, 옵션을 0.1초 만에 JSON Schema로 조회.
2. **AI 대화형 조건/배달비 협상 (`POST /api/v1/agent/negotiate`)**:
   - 옵션 및 배달지 주소에 따른 배달비와 총 결제금액을 서버가 실시간 확정 응답.
3. **A2A 직결 발주 (`POST /api/v1/agent/orders`)**:
   - 외부 AI가 결제 토큰과 함께 발주하면, 우리 서버가 D1 원자적 batch로 주문을 넣고 매장 단말기에서 벨이 울리고 주방 전표가 출력되도록 연결.

## 🌐 7. 환경 변화를 흡수하는 4대 확장성 (Extensibility Matrix)

| 확장 축 | 현재 기준 설계 | 향후 확장 영역 (코드 수정 없이 설정값 수용) | 확장 메커니즘 |
| :--- | :--- | :--- | :--- |
| **공급처 확장** | 소상공인 식당 (`str_`), 단위농협 하나로마트 (`mrt_`) | **로컬푸드 직매장, 지자체 공공급식센터, 전통시장 상인회, 청년농부 협동조합** | `supplier_type` 및 공급처 메타데이터 정책 분기 |
| **수요처 확장** | 일반 소비자 (`usr_`), 등록 경로당 (`fac_`) | **지역아동센터, 장애인 거주시설, 복지관 식당, 독거 어르신 가정** | `facility_type` 및 공공 수혜 바우처 매핑 |
| **정산 정책 확장** | 식당 일일 빠른정산, 하나로마트 격주(15일)/월말 마감 | **다중 자산 통합 정산 (신용카드, 카드사 포인트, 지역화폐, 스테이블코인) + 대리점 3.3% 원천징수 + 총판 전자세금계산서 (DOC-18)** | `settlement_policy` JSON (주기, 마감일, 정산소요일, 다중자산 대사 엔진) |
| **결제 수단 확장** | 신용카드 (`CREDIT_CARD`), 보조금 복지카드 (`WELFARE_CARD`) | **카드사 복합 포인트 (신한/현대/KB), 지자체 지역화폐 (서울페이/경기지역화폐/온누리), 스테이블 코인 (KRW 페깅/USDT/USDC) (DOC-18)** | `funding_source` & `payment_method` 플러그인 어댑터 |
