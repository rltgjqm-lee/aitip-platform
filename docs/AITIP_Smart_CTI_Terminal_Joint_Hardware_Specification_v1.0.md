## 📌 1. Project Background & Operational Context (공동 사업 개요 및 환경)

### 1.1. 공동 사업 추진 배경 (Joint Business Vision)
본 문서는 한국 O2O 가맹점 및 공공 인프라 시장에 보급할 **상용 전용 스마트 CTI(Computer Telephony Integration) 단말기**의 성공적인 양산을 위해, **AITIP(서비스 기획 및 비즈니스 아키텍처 총괄)**과 **하드웨어 제조 파트너사(설계·엔지니어링·양산 총괄)**가 원팀(One-Team)으로서 함께 개발할 하드웨어 기술 규격을 정의합니다.

기존의 고비용 PC 기반 POS나 단순 카드 단말기의 한계를 넘어, **"전화 물리 CTI 자동응답 + 클라우드 실시간 제어 + 외장 영수증 인쇄"**를 단독 기기로 완결 짓는 고신뢰성 임베디드 단말기를 공동 개발하여 시장에 독점 공급하는 것을 목표로 합니다.

### 1.2. 단말기 핵심 설계 목표 (Core Engineering Goals)
1. **무설정 플러그 앤 플레이 (10초 설치)**: 통신사나 키폰 기종에 관계없이 매장 현장에서 즉시 연결되는 범용 물리 인터페이스.
2. **24/7 통화 무결성 (Normally-Closed 물리 바이패스)**: 단말기 전원 꺼짐이나 비정상 상태에서도 매장 전화 통화가 절대 두절되지 않는 하드웨어 회로.
3. **AI 에이전트 엣지 게이트웨이**: 현장 전화 및 매장 인프라를 클라우드 AI 에이전트와 실시간으로 직결하는 안정적인 임베디드 플랫폼.

양사는 매장 환경에 맞추어 **터치스크린 일체형 모델(주력)**과 **헤드리스 모델(보조)** 2가지 폼팩터를 공동 라인업으로 구축합니다.

```

│                             AITIP 단말기 2대 폼팩터 구성                                 │
├────────────────────────────────────────────┬─────────────────────────────────────────────┤
│   [Model A: 일체형 스마트 데스크탑 단말기] │        [Model B: 컴팩트 헤드리스 게이트웨이] │
├────────────────────────────────────────────┼─────────────────────────────────────────────┤
│ • 7" ~ 10.1" 광시야각 IPS 디스플레이 내장  │ • 화면 없는 독립형 소형 임베디드 박스       │
│ • 정전식 멀티터치 (G+G 구조)               │ • 기존 PC POS 또는 별도 태블릿 보유 매장용  │
│ • 점주가 화면에서 즉시 주문 접수 및 관리  │ • 카운터 하부 또는 벽면 은닉 설치          │
│ • 매장 카운터 거치 스탠드 및 후면 월마운트│ • 초소형 ABS/메탈 케이스 (약 120x80x30 mm)   │
└────────────────────────────────────────────┴─────────────────────────────────────────────┘
```

### 2.1. Model A (7" ~ 10.1" Touchscreen Desktop Terminal) 상세
* **LCD 패널**: 7인치, 8인치, 또는 10.1인치 IPS LCD
  * 해상도: 1024 x 600 또는 1280 x 800 이상
  * 시야각: 광시야각 (상/하/좌/우 85도 이상)

  * 구조: Glass + Glass (G+G) 또는 산업용 방오 표면 처리 (식당 기름때 및 물기 내구성)
* **기구(Enclosure) 요구사항**:
  * 매장 카운터 배치용 틸트(Tilt) 각도 조절 스탠드 구조
  * 후면 표준 VESA 홀 또는 벽걸이(Wall-mount) 키홀 가공

## 📞 4. Dedicated CTI & Telephony Circuitry (물리 전화 특화 회로)

AITIP 단말기의 가장 핵심적인 하드웨어 차별화 요소는 **"통신사 종류(PSTN/VoIP)에 관계없이 전국의 어떤 전화기든 10초 만에 무설정 직결되고, 정전 시 100% 무전원 바이패스되는 물리 회로"**입니다.

```
                   +-------------------------------------------------------------+
                   |             AITIP Dedicated CTI Hardware Circuit            |
                   |                                                             |
 [PSTN 국선 / CPG] |  [RJ-11 Line In] ──> [ GDT / PTC 서지보호 ]                 |
                   |                             │                               |
                   |                      [ Si3050급 DAA ] ──> Ring 감지 / 오프훅|
                   |                             │                               |
                   |  [RJ-11 Phone Out]<─────────┘                               |
                   |                                                             |
                   |  [RJ-9 Handset In] ─────────────────────┐                   |
 [인터넷 키폰 수화기] |                                         ▼                   |
                   |                    [ Normally-Closed 기계식 릴레이 ]         |
                   |                      (전원 꺼짐 시: 본체 ↔ 수화기 100% 직결)  |
                   |                                         ▲                   |
 [인터넷 키폰 본체] |  [RJ-9 Base Out] ───────────────────────┘                   |
                   |                             │ (전원 켜짐 / CTI 작동 시)     |
                   |                             ▼                               |
                   |                      [ Analog MUX / 스위칭 ]                |
                   |                             │                               |
                   |              ┌──────────────┴──────────────┐                |
                   |              ▼                             ▼                |
                   |       [ Mic Audio Inject ]         [ DTMF 감지 / 오디오 In ]|
                   |       (안내 음성 DAC 주입)          (고객 키패드 하드웨어 디코딩)
                   +-------------------------------------------------------------+
```

### 4.1. [포트 1] Dual RJ-11 포트 (일반 국선 PSTN 및 CPG 모뎀용)
* **물리 커넥터**: RJ-11 6P2C/6P4C 암놈(Female) 소켓 2구 (`LINE IN`, `PHONE OUT`).
* **DAA 및 신호 절연 회로**:
  * Silicon Labs Si3050급 DAA(Direct Access Arrangement) 회로 실장.
  * 고전압 링(Ring) 감지 신호 인터럽트 라인.
  * PhotoMOS 반도체 릴레이 또는 전자식 오프훅(Off-Hook) 스위칭 제어.
* **서지 및 뇌서지 보호 회로**:
  * 옥외 인입 전화선의 유도뢰/서지 차단용 GDT(가스방전관) 및 PTC 서미스터 필수 실장.

### 4.2. [포트 2] Dual RJ-9 포트 (인터넷 키폰 수화기 직결용 - 핵심 특화 회로)
* **물리 커넥터**: RJ-9 (4P4C) 암놈(Female) 소켓 2구 기판 실장
  * `PHONE HANDSET IN`: 점주가 사용하던 키폰 수화기 직결.
  * `PHONE BASE OUT`: 키폰 본체 수화기 단자에 연결 (25cm 패치 케이블 번들).
* **무전원 물리 바이패스 릴레이 (Normally-Closed DPDT Relay)**:
  * **필수 조건**: 단말기 전원이 꺼져 있거나 보드가 부팅되지 않은 상태에서는 기계식 릴레이의 NC(Normally-Closed) 접점을 통해 **키폰 본체와 수화기 4선이 물리적으로 1:1 직결**되어야 함.
  * 이로써 단말기 고장이나 정전 시에도 식당 일반 전화 통화는 0.1%의 장애 없이 100% 정상 작동 보장.
* **통화 제어 및 오디오 스위칭**:
  * 수화기 4선 중 스피커 라인(1, 2번)과 마이크 라인(3, 4번)을 아날로그 MUX로 분리 제어.
  * **마이크 라인**: 단말기 저노이즈 오디오 DAC를 통해 키폰 본체로 "안내 멘트" 주입.
  * **스피커 라인**: 하드웨어 DTMF 디코더 IC(또는 오디오 코덱 입력)를 통해 고객이 누른 전화 버튼 신호 가로채기(Barge-in 지원).

## ⚡ 5. Power Architecture & Reliability (전원 및 안정성 설계)

### 5.1. 전원 입력 사양
* **입력 규격**: DC 12V / 1.5A ~ 2.0A (표준 DC 배럴 잭 커넥터).
* **온보드 전원단**: 고효율 DC-DC Step-Down Buck Converter (3.3V, 1.8V, 0.9V 등 SoC 및 주변장치 안정 공급).

### 5.2. 슈퍼커패시터(EDLC) 기반 강제 차단 방어 회로
* 식당 마감 시 멀티탭 강제 차단에 대응하기 위한 전원 유지 회로:
  * 12V 메인 입력단 차단 감지 즉시 CPU 전용 GPIO 인터럽트 신호 발생.
  * **EDLC 슈퍼커패시터 뱅크**를 통해 보드 핵심 전원을 **최소 0.5초 ~ 1.0초간 유지**.
  * 이 유예 시간 동안 진행 중인 CTI 릴레이의 안전 복귀 및 파일시스템 캐시 플러시(Sync) 완료.

### 5.3. RTC (Real Time Clock) 및 백업 배터리 회로
* **RTC IC**: PCF8563 또는 DS3231급 고정밀 I2C RTC 실장.
* **백업 배터리 홀더**: 코인 배터리(CR1220 또는 CR2032) 실장.
* **설계 목적**: 전원이 완전히 차단된 상태로 며칠간 방치되더라도 재부팅 시 정확한 시스템 시계를 즉시 유지하여, 보안 클라우드 통신(TLS 인증서 유효 시간 검증) 실패를 원천 차단.

### 5.4. 하드웨어 와치독 (Hardware Watchdog Timer)
* 메인보드 프리징 또는 비정상 루프 발생 시 하드웨어적으로 전원을 리셋하는 외부 WDT 회로 필수.

## 🐧 7. OS & Board Support Package (BSP) 요구사항

하드웨어 제조 파트너사는 보드 납품 시 다음 시스템 수준의 BSP 환경을 제공하여 상위 소프트웨어가 원활히 구동될 수 있도록 지원합니다:

1. **Linux Kernel LTS**: Linux Kernel 5.x 또는 6.x LTS 지원 (Debian 12 또는 Ubuntu 22.04 LTS 베이스).
2. **필수 드라이버 및 디바이스 트리(DTS) 포팅 완결**:
   * LCD 디스플레이 및 정전식 터치패널 I2C 드라이버
   * 오디오 코덱 (DAC 안내 음성 출력 및 ADC/DTMF 입력)
   * 듀얼 RJ-11/RJ-9 제어용 GPIO 핀 매핑 (릴레이 제어, Ring 감지, 전원 차단 감지)
   * RTC 및 외부 Watchdog 드라이버
   * RS-232C UART 및 USB 2.0 Host 컨트롤러
3. **SquashFS 및 A/B 듀얼 파티션 지원**:
   * OS 루트 파일시스템 읽기 전용(Read-Only SquashFS) 이미지 빌드 스크립트
   * 안전한 원격 펌웨어 업데이트(OTA)를 위한 A/B 듀얼 뱅크 부트로더(U-Boot) 구성

## 🤝 8. Strategic Market Opportunity & Joint Roadmap (전략적 틈새시장 및 공동 사업 체계)

### 8.1. Market Niche: The Gateway for AI Agents (게이트 하드웨어 틈새시장과 AI 에이전트 연동 가치)

1. **POS와 통신 분야가 방치한 게이트(Gate) 하드웨어의 완전한 공백**:
   - 현재 POS와 통신 분야는 각자의 기존 사업에만 빠져 있어, 매장 현장에서 양쪽을 이어주는 **게이트 역할을 하는 전문 하드웨어 서비스는 시장에 아무것도 없음**.
   - POS사는 결제와 계산기 기능에 묶여 있고, 통신사는 회선과 기본료 판매에만 갇혀 있어 복합적인 현장 게이트웨이를 제공하지 못함.

2. **AI & AI 에이전트 시장 선점을 위한 물리적 하드웨어의 필수성**:
   - 향후 AI 및 AI 에이전트로 연동되는 거대한 시장을 선점하기 위해서는, 소프트웨어만으로는 불가능하며 **현장 매장에 AI와 연동되고 대화할 수 있는 하드웨어(H/W)가 반드시 선점**되어 있어야 함.
   - 본 단말기는 POS와 통신 사이의 빈 공백을 채우고, 향후 오프라인 매장이 AI 에이전트 생태계와 직결되는 독점적 게이트웨이를 선점하므로 **양사 공동 사업으로서 매우 큰 성장 잠재력과 확고한 시장성을 지님**.

```
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│                            양사 공동 사업 협업 프레임워크                                 │
├────────────────────────────────────────────┬─────────────────────────────────────────────┤
│         [AITIP: 서비스 기획 & 사업화]       │       [파트너사: 하드웨어 엔지니어링 & 제조]  │
```

## 9. MQTT 실시간 중추망 연동에 따른 하드웨어 요구 규격 (Hardware Impact & Protocol Constraints)

### 9.1. 통신 프로토콜 개요 및 토폴로지 (공유기 무설정 아웃바운드)
* **방화벽 무설정 원칙 (Zero-Inbound Port)**:
  * 가맹점 인터넷 환경(KT, SKB, LGU+, 지역 케이블)의 공유기 포트포워딩, DDNS, DMZ 설정을 일절 요구하지 않는다.
  * 모든 통신은 단말기 내부에서 클라우드 브로커로 향하는 **순수 아웃바운드(Outbound TCP)**로만 성립된다.
* **이중화 포트 규격**:
  * 주 포트(Primary): **TCP 8883 (MQTTS - TLS 1.3 암호화 직결)**.
  * 보조 포트(Fallback): **TCP 443 (WSS - Secure WebSocket 터널링)**.
  * 매장 방화벽이나 통신사 공유기가 8883 비표준 포트를 차단하는 경우, 펌웨어 수준에서 3초 이내에 443 WSS로 자동 전환(Fallback)되어야 한다.
* **30초 Smart Keep-Alive (PINGREQ)**:
  * 국내 유무선 공유기의 NAT 세션 만료 시간(보통 60~120초)을 방어하기 위해 정확히 30초 주기로 MQTT PINGREQ를 송신하고 PINGRESP를 수신한다.
  * 월간 Keep-Alive 패킷 총량은 5MB 미만으로 초경량 유지.

### 9.2. Main SoC 및 메모리 하드웨어 요구 스펙 (Crypto Engine & RAM)
* **SoC 하드웨어 암호화 가속기 필수**:
  * TLS 1.3 암호화 통신(AES-128-GCM, SHA-256)을 소프트웨어만으로 연산 시 CPU 점유율이 급증하고 발열이 유발됨.
  * 따라서 메인 프로세서(Rockchip RK3566 또는 Allwinner H616 급)는 반드시 **하드웨어 암호화 가속 엔진(Hardware Crypto Engine)**을 탑재해야 한다.
* **메모리(RAM) 용량 및 버퍼 격리**:
  * 총 시스템 RAM: 최소 1GB (LPDDR3/LPDDR4).
  * OS 및 기본 런타임: 150MB~200MB 점유.
  * MQTT 메시징 및 송수신 소켓 버퍼: 최대 50MB 할당 (네트워크 일시 단절 시 인메모리 버퍼링).
  * UI/KDS 렌더링(Chromium/WebKit 임베디드 뷰): 300MB~400MB 할당.
  * 여유 마진: 300MB 이상 상시 확보하여 Out-Of-Memory(OOM) 킬러 작동을 원천 차단.

### 9.3. 플래시 스토리지 신뢰성 및 오프라인 큐 설계 (eMMC 5.1 & Wear-Leveling)
* **MicroSD 원천 배제 및 온보드 8GB eMMC 5.1 필수**:
  * 과거 기획의 MicroSD 슬롯 방식은 매장 내 진동, 접점 산화, 잦은 강제 전원 차단 시 블록 손상률이 15%를 초과함.
  * 반드시 JEDEC 표준 eMMC 5.1 규격 온보드 BGA 실장 칩을 사용해야 함.
* **파티션 분할 및 쓰기 보호 정책**:
  * 파티션 1 (OS Root): Read-Only SquashFS (A/B 이중 뱅크로 OTA 안전성 확보).
  * 파티션 2 (Writable /data): 2GB 저널링 파일시스템 (EXT4 or F2FS).
* **오프라인 주문 큐(Offline Order Queue) 신뢰성 규격**:
  * 외부 인터넷 단절 시에도 CTI 전화 인입 로그 및 카운터 포스 주문 데이터가 유실되지 않도록 최대 10,000건(약 20MB)의 로컬 영속성 큐를 보존.
  * 네트워크 복구 즉시 QoS 1(At least once) 기반으로 클라우드에 자동 순차 발행(Re-sync).
  * eMMC 수명 보호를 위해 잦은 단편적 쓰기를 지양하고, 5초 배치 저널링 및 RAM 버퍼 플러시 전략을 채택하여 eMMC 쓰기 수명 10년 이상 보장.

### 9.4. 슈퍼커패시터(EDLC) 전원 단절 방어 타임라인 (Power-Loss Protection)
* **비정상 전원 차단 시 하드웨어 방어 시퀀스**:
  * 식당 마감 시 점주가 카운터 멀티탭 스위치를 즉시 끄는 운영 환경에 100% 대응.
  * 12V 메인 전원 차단 감지(Comparator 회로) 즉시 SoC 전용 Non-Maskable Interrupt(NMI) 발생.
  * 온보드 EDLC 슈퍼커패시터(슈퍼캡) 뱅크가 **최소 500ms ~ 1000ms 동안 보드 핵심 전원(3.3V/1.8V/0.9V)을 연속 공급**.
* **500ms 골든타임 내 소프트웨어 완결 작업**:
  1. 0~50ms: 진행 중인 CTI 기계식 릴레이를 즉시 Normally-Closed(NC) 기본 상태로 안전 복귀 (전화 불통 방지).
  2. 50~150ms: MQTT 연결에 대해 Broker로 Clean Disconnect 패킷 송신 (Last Will Testament 불필요 트리거 억제).
  3. 150~350ms: 로컬 저널링 파일시스템 캐시 플러시 (sync) 및 진행 중인 영수증 프린터 UART 송신 완료.
  4. 350~500ms: CPU Halt 및 안전 정지.

### 9.5. RTC 백업 배터리 및 하드웨어 와치독(WDT) 연동
* **RTC(Real Time Clock)와 TLS 보안 인증서 상관관계**:
  * MQTTS 통신은 서버의 X.509 TLS 인증서 유효기간(Not Before / Not After) 검증을 거침.
  * 장기 휴무(명절, 연휴) 후 전원이 들어왔을 때 RTC 배터리가 방전되어 시스템 시간이 1970-01-01로 초기화되면 **TLS 핸드셰이크가 무조건 거부되어 클라우드 접속이 영구 두절**됨.
  * 고정밀 I2C RTC (PCF8563 또는 DS3231) + CR1220/CR2032 교체형 코인 배터리를 필수 장착하여 전원 차단 상태에서도 3년 이상 시계 오차 ±2ppm 이내 유지.
* **하드웨어 와치독 타이머 (External Hardware WDT)**:
  * 리눅스 소프트웨어 내부 락업(Soft Lockup)에 대비하여 외부 하드웨어 WDT IC 필수 배치.
  * MQTT 클라이언트 및 텔레포니 데몬이 60초마다 WDT 핀을 토글(Heartbeat Kick)하며, 60초간 토글 부재 시 자동 하드웨어 하드리셋 수행.

### 9.6. CTI 회로 인터럽트 및 영수증 프린터 UART 인터페이스
* **Si3050 DAA 링(Ring) 감지 및 지연시간(Latency) 규격**:
  * 전화선에서 Ring 신호(75Vrms, 20Hz) 인입 시 Si3050 DAA가 하드웨어 인터럽트 발생.
  * SoC가 인터럽트를 수신하여 UART를 통해 CID(발신번호)를 수집하고, 이를 MQTT 토픽(`aitip/devices/{deviceId}/telephony`)으로 클라우드에 발행하기까지의 총 지연시간은 **최대 50ms 이내**로 제한.
  * 이를 통해 매장 전화벨이 1회 울리는 즉시 점주 KDS 화면에 고객 팝업이 0.1초 만에 표출됨.
* **ESC/POS 영수증 프린터 UART 규격 (115200bps RTS/CTS)**:
  * RS-232C 또는 내부 UART 프린터 포트는 115200bps 보드레이트 사용.
  * 하드웨어 흐름제어(RTS/CTS) 회로를 반드시 실장하여 대용량 주방 전표(그래픽, 한글 폰트, 바코드) 인쇄 시 프린터 버퍼 오버플로우로 인한 문자 깨짐을 원천 차단.
  * 피크 전류: 써멀 헤드 및 커터 작동 시 24V 2.5A 피크 전류를 감당할 수 있도록 전원 분리 설계.
