## 📌 1. Project Background & Operational Context (공동 사업 개요 및 환경)

### 1.1. 공동 사업 추진 배경 (Joint Business Vision)
본 문서는 한국 O2O 가맹점 및 공공 인프라 시장에 보급할 **상용 전용 스마트 CTI(Computer Telephony Integration) 단말기**의 성공적인 양산을 위해, **AITIP(서비스 기획 및 비즈니스 아키텍처 총괄)**과 **하드웨어 제조 파트너사(설계·엔지니어링·양산 총괄)**가 원팀(One-Team)으로서 함께 개발할 하드웨어 기술 규격을 정의합니다.

기존의 고비용 PC 기반 POS나 단순 카드 단말기의 한계를 넘어, **"전화 물리 CTI 자동응답 + 클라우드 실시간 제어 + 외장 영수증 인쇄"**를 단독 기기로 완결 짓는 고신뢰성 임베디드 단말기를 공동 개발하여 시장에 독점 공급하는 것을 목표로 합니다.

### 1.2. 단말기 핵심 설계 목표 (Core Engineering Goals)
1. **무설정 플러그 앤 플레이 (10초 설치)**: 통신사나 키폰 기종에 관계없이 매장 현장에서 즉시 연결되는 범용 물리 인터페이스.
2. **24/7 통화 무결성 (Normally-Closed 물리 바이패스)**: 단말기 전원 꺼짐이나 비정상 상태에서도 매장 전화 통화가 절대 두절되지 않는 하드웨어 회로.
3. **AI 에이전트 엣지 게이트웨이**: 현장 전화 및 매장 인프라를 클라우드 AI 에이전트와 실시간으로 직결하는 안정적인 임베디드 플랫폼.

  * 후면 표준 VESA 홀 또는 벽걸이(Wall-mount) 키홀 가공

## 📞 4. Dedicated CTI & Telephony Circuitry (물리 전화 특화 회로)

AITIP 단말기의 가장 핵심적인 하드웨어 차별화 요소는 **"통신사 종류(PSTN/VoIP)에 관계없이 전국의 어떤 전화기든 10초 만에 무설정 직결되고, 정전 시 100% 무전원 바이패스되는 물리 회로"**입니다.

```
                   +-------------------------------------------------------------+
                   |             AITIP Dedicated CTI Hardware Circuit            |
                   |                                                             |
 [PSTN 국선 / CPG] |  [RJ-11 Line In] ──> [ GDT / PTC 서지보호 ]                 |
                   |                             │                               |
                   |                      [ Si3050급 DAA ] ──> Ring 감지 / 오프훅|
                   |                             │                               |
                   |  [RJ-11 Phone Out]<─────────┘                               |
                   |                                                             |
                   |  [RJ-9 Handset In] ─────────────────────┐                   |
 [인터넷 키폰 수화기] |                                         ▼                   |
                   |                    [ Normally-Closed 기계식 릴레이 ]         |
                   |                      (전원 꺼짐 시: 본체 ↔ 수화기 100% 직결)  |
                   |                                         ▲                   |
 [인터넷 키폰 본체] |  [RJ-9 Base Out] ───────────────────────┘                   |
                   |                             │ (전원 켜짐 / CTI 작동 시)     |
                   |                             ▼                               |
                   |                      [ Analog MUX / 스위칭 ]                |
                   |                             │                               |
                   |              ┌──────────────┴──────────────┐                |
                   |              ▼                             ▼                |
                   |       [ Mic Audio Inject ]         [ DTMF 감지 / 오디오 In ]|
                   |       (안내 음성 DAC 주입)          (고객 키패드 하드웨어 디코딩)
                   +-------------------------------------------------------------+
```

### 4.1. [포트 1] Dual RJ-11 포트 (일반 국선 PSTN 및 CPG 모뎀용)
* **물리 커넥터**: RJ-11 6P2C/6P4C 암놈(Female) 소켓 2구 (`LINE IN`, `PHONE OUT`).
* **DAA 및 신호 절연 회로**:
  * Silicon Labs Si3050급 DAA(Direct Access Arrangement) 회로 실장.
  * 고전압 링(Ring) 감지 신호 인터럽트 라인.
  * PhotoMOS 반도체 릴레이 또는 전자식 오프훅(Off-Hook) 스위칭 제어.
* **서지 및 뇌서지 보호 회로**:
  * 옥외 인입 전화선의 유도뢰/서지 차단용 GDT(가스방전관) 및 PTC 서미스터 필수 실장.

### 4.2. [포트 2] Dual RJ-9 포트 (인터넷 키폰 수화기 직결용 - 핵심 특화 회로)
* **물리 커넥터**: RJ-9 (4P4C) 암놈(Female) 소켓 2구 기판 실장
  * `PHONE HANDSET IN`: 점주가 사용하던 키폰 수화기 직결.
  * `PHONE BASE OUT`: 키폰 본체 수화기 단자에 연결 (25cm 패치 케이블 번들).
* **무전원 물리 바이패스 릴레이 (Normally-Closed DPDT Relay)**:
  * **필수 조건**: 단말기 전원이 꺼져 있거나 보드가 부팅되지 않은 상태에서는 기계식 릴레이의 NC(Normally-Closed) 접점을 통해 **키폰 본체와 수화기 4선이 물리적으로 1:1 직결**되어야 함.
  * 이로써 단말기 고장이나 정전 시에도 식당 일반 전화 통화는 0.1%의 장애 없이 100% 정상 작동 보장.
* **통화 제어 및 오디오 스위칭**:
  * 수화기 4선 중 스피커 라인(1, 2번)과 마이크 라인(3, 4번)을 아날로그 MUX로 분리 제어.
  * **마이크 라인**: 단말기 저노이즈 오디오 DAC를 통해 키폰 본체로 "안내 멘트" 주입.
  * **스피커 라인**: 하드웨어 DTMF 디코더 IC(또는 오디오 코덱 입력)를 통해 고객이 누른 전화 버튼 신호 가로채기(Barge-in 지원).

## ⚡ 5. Power Architecture & Reliability (전원 및 안정성 설계)

### 5.1. 전원 입력 사양
* **입력 규격**: DC 12V / 1.5A ~ 2.0A (표준 DC 배럴 잭 커넥터).
* **온보드 전원단**: 고효율 DC-DC Step-Down Buck Converter (3.3V, 1.8V, 0.9V 등 SoC 및 주변장치 안정 공급).

### 5.2. 슈퍼커패시터(EDLC) 기반 강제 차단 방어 회로
* 식당 마감 시 멀티탭 강제 차단에 대응하기 위한 전원 유지 회로:
  * 12V 메인 입력단 차단 감지 즉시 CPU 전용 GPIO 인터럽트 신호 발생.
  * **EDLC 슈퍼커패시터 뱅크**를 통해 보드 핵심 전원을 **최소 0.5초 ~ 1.0초간 유지**.
  * 이 유예 시간 동안 진행 중인 CTI 릴레이의 안전 복귀 및 파일시스템 캐시 플러시(Sync) 완료.

### 5.3. RTC (Real Time Clock) 및 백업 배터리 회로
* **RTC IC**: PCF8563 또는 DS3231급 고정밀 I2C RTC 실장.
* **백업 배터리 홀더**: 코인 배터리(CR1220 또는 CR2032) 실장.
* **설계 목적**: 전원이 완전히 차단된 상태로 며칠간 방치되더라도 재부팅 시 정확한 시스템 시계를 즉시 유지하여, 보안 클라우드 통신(TLS 인증서 유효 시간 검증) 실패를 원천 차단.

### 5.4. 하드웨어 와치독 (Hardware Watchdog Timer)
* 메인보드 프리징 또는 비정상 루프 발생 시 하드웨어적으로 전원을 리셋하는 외부 WDT 회로 필수.

## 🐧 7. OS & Board Support Package (BSP) 요구사항

하드웨어 제조 파트너사는 보드 납품 시 다음 시스템 수준의 BSP 환경을 제공하여 상위 소프트웨어가 원활히 구동될 수 있도록 지원합니다:

1. **Linux Kernel LTS**: Linux Kernel 5.x 또는 6.x LTS 지원 (Debian 12 또는 Ubuntu 22.04 LTS 베이스).
2. **필수 드라이버 및 디바이스 트리(DTS) 포팅 완결**:
   * LCD 디스플레이 및 정전식 터치패널 I2C 드라이버
   * 오디오 코덱 (DAC 안내 음성 출력 및 ADC/DTMF 입력)
   * 듀얼 RJ-11/RJ-9 제어용 GPIO 핀 매핑 (릴레이 제어, Ring 감지, 전원 차단 감지)
   * RTC 및 외부 Watchdog 드라이버
   * RS-232C UART 및 USB 2.0 Host 컨트롤러
3. **SquashFS 및 A/B 듀얼 파티션 지원**:
   * OS 루트 파일시스템 읽기 전용(Read-Only SquashFS) 이미지 빌드 스크립트
   * 안전한 원격 펌웨어 업데이트(OTA)를 위한 A/B 듀얼 뱅크 부트로더(U-Boot) 구성

## 🤝 8. Strategic Market Opportunity & Joint Roadmap (전략적 틈새시장 및 공동 사업 체계)

### 8.1. Market Niche: The Gateway for AI Agents (게이트 하드웨어 틈새시장과 AI 에이전트 연동 가치)

1. **POS와 통신 분야가 방치한 게이트(Gate) 하드웨어의 완전한 공백**:
   - 현재 POS와 통신 분야는 각자의 기존 사업에만 빠져 있어, 매장 현장에서 양쪽을 이어주는 **게이트 역할을 하는 전문 하드웨어 서비스는 시장에 아무것도 없음**.
   - POS사는 결제와 계산기 기능에 묶여 있고, 통신사는 회선과 기본료 판매에만 갇혀 있어 복합적인 현장 게이트웨이를 제공하지 못함.

2. **AI & AI 에이전트 시장 선점을 위한 물리적 하드웨어의 필수성**:
   - 향후 AI 및 AI 에이전트로 연동되는 거대한 시장을 선점하기 위해서는, 소프트웨어만으로는 불가능하며 **현장 매장에 AI와 연동되고 대화할 수 있는 하드웨어(H/W)가 반드시 선점**되어 있어야 함.
   - 본 단말기는 POS와 통신 사이의 빈 공백을 채우고, 향후 오프라인 매장이 AI 에이전트 생태계와 직결되는 독점적 게이트웨이를 선점하므로 **양사 공동 사업으로서 매우 큰 성장 잠재력과 확고한 시장성을 지님**.

### 8.3. 공동 추진 마일스톤 (Joint Roadmap)
1. **1단계: 기술 협의 및 회로 검토 (Technical Alignment)**
   - 본 규격서를 바탕으로 양사 엔지니어링 킥오프
   - 파트너사 기존 플랫폼 기반 특화 회로(CTI/릴레이/전원보호) 결합 방안 확정
2. **2단계: 시제품 제작 (EVT / DVT Sample)**
   - 1차 엔지니어링 샘플 보드 제작 (10~20대)
   - 리눅스 BSP 드라이버 검증 및 기본 전화 물리 바이패스 시험
3. **3단계: 한국 현장 실증 (Field Pilot)**
   - 한국 가맹점 현장에 샘플 단말기 투입 (KT/LGU+/SKB 다양한 키폰 기종 100% 직결 검증)
   - 상위 서비스 소프트웨어 연동 및 피드백 반영
4. **4단계: KC 인증 및 양산 출하 (Certification & MP)**
   - 한국 KC 전파인증(EMC) 시험 통과
   - 양산 공정 조립 및 한국 시장 대량 보급 개시
