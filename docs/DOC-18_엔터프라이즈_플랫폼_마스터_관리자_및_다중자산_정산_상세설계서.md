## 📌 제 1 장. 개요 및 글로벌 5대 서비스 벤치마크 총람

### 1.1 배경 및 목적
AITIP 플랫폼은 단순히 온라인 음식 주문 중개에 머무는 웹 서비스가 아니며, **'현장 하드웨어 단말기(Smart CTI) + 전국 광역/지역 유통망 + 다중 결제자산(신용카드, 카드사 포인트, 지자체 지역화폐, 스테이블코인)'**이 결합된 하이브리드 온·오프라인 융합 플랫폼이다.

영세 상인을 착취하는 기존 배달 독점 플랫폼의 약탈적 광고(깃발 꽂기 등)와 과도한 중개 수수료 체계를 원천 배제하고, 전국 단위 가맹점과 지역 대리점이 함께 성장하는 지속 가능한 법인 생태계를 완성하기 위해, 본 설계서는 글로벌 1위 엔터프라이즈 플랫폼들의 검증된 백오피스 아키텍처를 계승하여 AITIP 마스터 관리자(Platform Master Admin)의 10대 핵심 관제 체계를 규격화한다.

```

========================================================================================================================
1. Clover (Fiserv)       : 독립 대리점(ISO) 3계층망 + 50~70% 결제 마크업 평생 레지듀얼(Vested Residuals) + 3자 대사
```

### 2.1 계층별 권한 및 역할 정의
1. **광역 총판 (Master Distributor / 접두사 `dst_`)**:
   - 전국 17개 특별시/광역시/도 단위 독점 영업권 보유 법인
   - 산하 지역 대리점 계약 체결 및 권역 할당 권한
   - 본사로부터 하드웨어 단말기를 대량 수급하여 산하 대리점에 공급
   - 세무 증빙: 법인 간 거래 전자세금계산서 청구
2. **지역 대리점 (Local Agency / 접두사 `agn_`)**:
   - 226개 시/군/구 단위 및 단위농협 연계 현장 법인/개인사업자
   - 관할 지역 내 소상공인 치킨집, 식당, 마트 영업 및 하드웨어 현장 설치
   - 가맹점 장애 발생 시 1차 현장 A/S 출동 및 CTI 라인 점검
   - 세무 증빙: 사업소득세(3.0%) + 지방소득세(0.3%) = 총 3.3% 원천징수 대상
3. **현장 영업사원 (Field Sales Rep / 접두사 `fsr_`)**:
   - 대리점 소속의 상가 방문 매니저
   - 가맹점 신청서 접수, 사업자등록증 진위 대조, 메뉴판 사진 수집 및 단말기 시연
   - 가맹점 온보딩 완료 시 1회성 유치 수당 수령

## 📦 제 3 장. 하드웨어 스마트 단말기 물류 및 생애주기 관제

AITIP CTI 스마트 단말기(Dual DAA + Dual DPDT + ESC/POS 프린터 일체형)의 분실, 유출, 부정 사용을 방지하고 전국 유통을 통제하기 위한 전주기 상태 머신이다.

```
[1. FACTORY_STOCKED] ➔ [2. ASSIGNED_DISTRIBUTOR] ➔ [3. ALLOCATED_AGENCY] ➔ [4. INSTALLED_MERCHANT] ➔ [5. ONLINE_ACTIVE]
       본사 창고 입고             총판 출고 배정                  대리점 출고                가맹점 MAC/시리얼 매핑         MQTT 정상 가동
                                                                                               │
                                                                                               ▼ (고장/해지 발생 시)
                                                                                  [6. RETURN_MAINTENANCE / RMA]
                                                                                             단말기 회수 및 수리
```

1. **시리얼 체계 (DOC-00 준수)**:
   - 기기 식별자: TypeID `dev_01...` (30자리 영구 고유 식별자)
   - 기기 바코드 시리얼: 제조연월(6) + 하드웨어리비전(2) + 일련번호(6) (예: `2611-H2-004819`)
   - MAC 주소 및 암호화 칩(ATECC608) 고유 공개키 인증서 사전 바인딩
2. **물류 이력 추적**:
   - 총판/대리점 관리자 화면에서 단말기 바코드 스캔 한 번으로 소속 조직 자동 이관
   - 가맹점 배정 시 점포 ID(`str_...`)와 1:1 결합(Pairing)되며, 임의로 타 매장으로 이전 설치 시 보안 알람 발생

## 💳 제 4 장. 다중 자산 결제 & 통합 정산 엔진 (Multi-Asset Settlement Engine)

'수수료 0원'이라는 단정적·비현실적 표현을 전면 배제하고, 결제망 원가와 다중 자산(카드사 포인트, 지역화폐, 스테이블코인)의 유통 원리를 정밀하게 반영한 차세대 정산 엔진이다.

### 4.1 4대 결제수단별 정산 프로세스 및 원가 구조

```
========================================================================================================================
결제 자산 구분          승인/취소 통신망            정산 주기          원가 및 수수료 구조               세무 증빙 처리
========================================================================================================================
1. 신용/체크카드        PG사 VAN/간편결제 망        D+1 ~ D+2 영업일   영세 0.5% ~ 일반 1.5% 원천 차감   여신금융협회 매입 자료
2. 카드사 복합포인트    카드사 포인트 API 결제      D+1 ~ D+3 영업일   포인트 수수료 차감 후 현금 입금   신용카드 매출전표 합산
3. 지자체 지역화폐      서울페이/지역사랑상품권 API D+2 ~ D+3 영업일   지자체 지원 할인액 국고 정산      현금영수증 지출증빙 규격
4. 스테이블 코인(Web3)  Polygon/Solana 온체인 블록체인 실시간 (블록 컨펌) 온체인 가스비(네트워크 원가)     디지털자산 거래명세서/원화환전
========================================================================================================================
```

### 4.2 계층별 정산 수식 명세

#### 1) 가맹점(Merchant) 일일 정산 수식
```
[가맹점 일일 순지급액 (Net Payout)] =
      총 결제 매출액 (A: 상품 주문금액 + 고객부담 배달팁 + 매장 식사비)
    + 본사/지자체 프로모션 지원금 (B: 할인쿠폰 본사부담금 + 지자체 지역화폐 보조금)
    + 카드사 포인트 본사 보전금 (C)
    - 결제망 원천 실비 수수료 (D: PG사 신용카드 결제 실비 수수료)
    - 배달대행사 위탁 배달비 차감액 (E: 부릉/생각대로/바로고 호출 건수 × 건당 실비)
    - 고객 환불/취소 시 가맹점 귀책 차감액 (F: DOC-12 분쟁 판정 결과)
```

#### 2) 지역 대리점(Agency) 월간 수당 수식
```
[대리점 월간 실수령액 (Net Commission)] =
    [총 발생 수당 (Gross)] - [원천징수 세액 3.3%]

where 총 발생 수당 (Gross) =
      (신규 입점 가맹점 수 × 건당 설치 인센티브 [예: 50,000원])
    + (실시간 활성 단말기 수 × 월간 유지관리비 [예: 10,000원])
    + (관할 가맹점 총 결제 거래액 [GMV] × 대리점 마진 쉐어 요율 [예: 0.2%])

where 원천징수 세액 =
      Gross × 3.0% (사업소득세) + Gross × 0.3% (지방소득세)
```

#### 3) 광역 총판(Master Distributor) 월간 마진 수식
```
[총판 월간 세금계산서 청구액] =
    [총판 공급가액] + [부가가치세 10%]

where 총판 공급가액 =
      (산하 전체 대리점 총 결제 거래액 [GMV] × 총판 오버라이딩 요율 [예: 0.1%])
    + (단말기 출고 대수 × 하드웨어 도매 유통 마진 차익)
    + (분기별/월별 권역 목표 달성 인센티브)
```

## 📊 제 5 장. 내부 세무 · 회계 및 재무 통제 체계 (Financial & Tax Control)

```

|                         [PG사 / 카드사 승인 원장] (Payment Gateway Master)                         |
+---------------------------------------------------------------------------------------------------+
                                                  │
                                                  ▼ (매일 새벽 03:00 배치 대사)
+---------------------------------------------------------------------------------------------------+
|               [삼자 대사 엔진 (Three-Way Reconciliation Engine)] - DOC-15                         |
|   1. PG 승인 원장(카드/지역화폐/포인트)  vs  2. 가맹점 정산 테이블  vs  3. 은행 펌뱅킹 출금 실적   |
|   => 불일치 오차(Mismatch) 발생 시 1원 단위 추적 / 슬리피지(Slippage) 보정 / 담당자 즉시 락        |
+---------------------------------------------------------------------------------------------------+
                                                  │
                         ┌────────────────────────┴────────────────────────┐
                         ▼                                                 ▼
+-------------------------------------------------+  +-------------------------------------------------+
|       [국세청 홈택스 표준 부가세 신고 자료]     |  |          [원천징수 및 전자세금계산서]           |
| - 분기별 가맹점 신용카드/현금영수증/지역화폐    |  | - 대리점 사업소득세 원천징수영수증 자동 생성   |
|   매출 내역 일괄 CSV 다운로드                   |  | - 총판 마진 법인 전자세금계산서 역발행/발행     |
| - 부가가치세법 제32조의2(신용카드등매출전표)    |  | - 국세청 전자세금계산서 연동 표준 XML/API 전송  |
+-------------------------------------------------+  +-------------------------------------------------+
```

## 🌐 제 6 장. 외부 연동 게이트웨이 허브 (Third-Party Integration Hub)

외부 서드파티 통신망과 API의 장애가 플랫폼 전체로 번지지 않도록 완충하고 실시간 헬스체크를 수행하는 중앙 연동 허브이다.

```
                                  [외부 연동 게이트웨이 허브 (Integration Hub)]
                                                        │
         ┌──────────────────┬───────────────────┼───────────────────┬──────────────────┐
         ▼                  ▼                   ▼                   ▼                  ▼
+------------------+ +------------------+ +-------------------+ +----------------+ +------------------+
| [PG/결제 게이트웨이| | [통신사 CTI 허브]  | | [메시징 게이트웨이] | |[배달대행사 API]  | | [AI 에이전트 허브] |
| - 토스페이먼츠    | | - SKB/KT/LGU+   | | - 카카오 비즈엠   | | - 부릉 (Vroong) | | - Gemini Live API|
| - NH농협 제로페이 | | - 0504 가상번호 | |   알림톡 템플릿   | | - 생각대로     | | - 통화음성 A2A   |
| - 지역화폐 API    | | - KS규격 CID    | | - SMS/LMS 대체경로| | - 바로고       | | - 이상거래 FDS   |
| - Web3 RPC 노드  | |   가상 COM 브릿지| |   (Failover)      | | - 할증요율 동기화| |   실시간 관제    |
+------------------+ +------------------+ +-------------------+ +----------------+ +------------------+
```

1. **서킷 브레이커 (Circuit Breaker)**:
   - 외부 API(배달대행사, 통신사, 알림톡)의 응답 지연이 3초를 초과하거나 5회 연속 5xx 에러 발생 시 즉시 우회(Fallback) 처리
2. **데드 레터 큐 (Dead Letter Queue / DLQ)**:
   - 네트워크 일시 단절로 실패한 웹훅 및 정산 트랜잭션을 최대 72시간 동안 보관하며, 지수 백오프(Exponential Backoff: 10초, 30초, 1분, 5분...) 알고리즘으로 자동 재시도

## 🔒 제 8 장. 엔터프라이즈 보안, RBAC 권한 분리 및 불변 감사 추적

### 8.1 5대 역할 기반 접근 제어 (RBAC)
1. **슈퍼 관리자 (Super Admin)**: 본사 최고 책임자. 전 메뉴 및 시스템 환경변수, 펌웨어 OTA 배포 승인 권한
2. **재무 감사관 (Financial Auditor)**: 다중 자산 정산 승인, PG 대사, 홈택스 세무 자료, 은행 펌뱅킹 이체 승인 권한
3. **광역 총판 관리자 (Distributor Admin)**: 산하 대리점 목록 조회, 권역 단말기 재고 배정, 총판 마진 계산서 조회
4. **지역 대리점 관리자 (Agency Admin)**: 관할 가맹점 온보딩 신청, 단말기 시리얼 등록, 대리점 3.3% 수당 명세서 조회
5. **CS 운영 상담원 (Support Specialist)**: 전국 주문 모니터링, DOC-12 분쟁 접수, 라이더 배차 현황 조회 (정산 및 시스템 설정 접근 불가)

### 8.2 불변 감사 추적 (Immutable Audit Trail)
모든 관리자 행위(가맹점 계좌번호 수정, 단말기 강제 릴리즈, 분쟁 환불금 승인 등)는 `audit_logs` 테이블에 변경 전/후 JSON 스냅샷과 함께 관리자 IP, 세션 ID, 타임스탬프를 암호화 해시(SHA-256) 체인으로 영구 기록한다.

## 🗄️ 제 9 장. 데이터베이스 스키마 확장안 (TypeID 엄격 준수)

기존 `schema_aitip_v01.sql`에 본 설계서의 3계층 유통망 및 다중 자산 정산 항목을 수용하기 위한 D1 SQLite 스키마 확장 정의이다.

```sql
-- ============================================================================
-- [DOC-18] 1. 광역 총판 (Master Distributors)
-- ============================================================================
CREATE TABLE master_distributors (
    id                 TEXT PRIMARY KEY
                       CONSTRAINT chk_dst_id CHECK (length(id) = 30 AND id GLOB 'dst_[0-7]*'),
    name               TEXT NOT NULL,
    biz_number         TEXT NOT NULL UNIQUE,
    rep_name           TEXT NOT NULL,
    phone              TEXT NOT NULL,
    territory_code     TEXT NOT NULL UNIQUE, -- 17개 시/도 행정표준코드 (예: '11' 서울, '41' 경기)
    territory_name     TEXT NOT NULL,
    overriding_rate    REAL NOT NULL DEFAULT 0.001, -- 0.1% 오버라이딩 지분율
    bank_name          TEXT NOT NULL,
    account_number     TEXT NOT NULL,
    account_holder     TEXT NOT NULL,
    status             TEXT NOT NULL DEFAULT 'ACTIVE' CHECK (status IN ('ACTIVE', 'SUSPENDED', 'TERMINATED')),
    created_at         INTEGER NOT NULL,
    updated_at         INTEGER NOT NULL
);

-- ============================================================================
-- [DOC-18] 2. 지역 대리점 (Local Agencies)
-- ============================================================================
CREATE TABLE local_agencies (
    id                 TEXT PRIMARY KEY
                       CONSTRAINT chk_agn_id CHECK (length(id) = 30 AND id GLOB 'agn_[0-7]*'),
    distributor_id     TEXT NOT NULL REFERENCES master_distributors(id),
    name               TEXT NOT NULL,
    biz_number         TEXT NOT NULL,
    rep_name           TEXT NOT NULL,
    phone              TEXT NOT NULL,
    region_code        TEXT NOT NULL UNIQUE, -- 226개 시/군/구 법정동 코드 (예: '11650' 서초구)
    region_name        TEXT NOT NULL,
    onboarding_bounty  INTEGER NOT NULL DEFAULT 50000, -- 신규 가맹점당 유치 수당 (50,000원)
    monthly_device_fee INTEGER NOT NULL DEFAULT 10000, -- 단말기당 월 유지보수비 (10,000원)
    gmv_share_rate     REAL NOT NULL DEFAULT 0.002,    -- 가맹점 거래액 마진 쉐어 (0.2%)
    tax_type           TEXT NOT NULL DEFAULT 'BUSINESS_3_3' CHECK (tax_type IN ('CORPORATE', 'BUSINESS_3_3')),
    bank_name          TEXT NOT NULL,
    account_number     TEXT NOT NULL,
    account_holder     TEXT NOT NULL,
    status             TEXT NOT NULL DEFAULT 'ACTIVE' CHECK (status IN ('ACTIVE', 'SUSPENDED', 'TERMINATED')),
    created_at         INTEGER NOT NULL,
    updated_at         INTEGER NOT NULL
);

-- ============================================================================
-- [DOC-18] 3. 다중 자산 결제 거래 원장 (Multi-Asset Transactions)
-- ============================================================================
CREATE TABLE multi_asset_transactions (
    id                 TEXT PRIMARY KEY
                       CONSTRAINT chk_mat_id CHECK (length(id) = 30 AND id GLOB 'mat_[0-7]*'),
    order_id           TEXT NOT NULL REFERENCES orders(id),
    asset_type         TEXT NOT NULL CHECK (asset_type IN ('CREDIT_CARD', 'CARD_POINT', 'LOCAL_CURRENCY', 'STABLECOIN')),
    currency_symbol    TEXT NOT NULL, -- 'KRW', 'SHINHAN_POINT', 'SEOUL_PAY', 'USDT'
    gross_amount       INTEGER NOT NULL, -- 원화 환산 승인액
    raw_asset_amount   REAL NOT NULL,    -- 원래 자산 수량 (예: 15.20 USDT, 5000 Point)
    network_fee        INTEGER NOT NULL DEFAULT 0, -- PG사 실비 수수료 또는 블록체인 가스비
    tx_hash_or_auth    TEXT,             -- 신용카드 승인번호 또는 블록체인 TxHash
    reconciled_status  TEXT NOT NULL DEFAULT 'PENDING' CHECK (reconciled_status IN ('PENDING', 'MATCHED', 'MISMATCH')),
    created_at         INTEGER NOT NULL
);

-- ============================================================================
-- [DOC-18] 4. 대리점 월간 수당 정산 원장 (Agency Monthly Settlements)
-- ============================================================================
CREATE TABLE agency_monthly_settlements (
    id                 TEXT PRIMARY KEY
                       CONSTRAINT chk_sag_id CHECK (length(id) = 30 AND id GLOB 'sag_[0-7]*'),
    agency_id          TEXT NOT NULL REFERENCES local_agencies(id),
    settlement_month   TEXT NOT NULL, -- 'YYYY-MM'
    active_device_cnt  INTEGER NOT NULL DEFAULT 0,
    new_merchant_cnt   INTEGER NOT NULL DEFAULT 0,
    total_gmv          INTEGER NOT NULL DEFAULT 0,
    bounty_amount      INTEGER NOT NULL DEFAULT 0, -- 유치 수당
    device_maint_amt   INTEGER NOT NULL DEFAULT 0, -- 단말기 유지비
    gmv_share_amount   INTEGER NOT NULL DEFAULT 0, -- GMV 마진 쉐어
    gross_payout       INTEGER NOT NULL,           -- 총 발생 수당
    withholding_tax    INTEGER NOT NULL,           -- 소득세 (3.0%)
    local_income_tax   INTEGER NOT NULL,           -- 지방소득세 (0.3%)
    net_payout_amount  INTEGER NOT NULL,           -- 실수령액
    status             TEXT NOT NULL DEFAULT 'CALCULATED' CHECK (status IN ('CALCULATED', 'APPROVED', 'TRANSFERRED', 'HELD')),
    created_at         INTEGER NOT NULL,
    updated_at         INTEGER NOT NULL,
    UNIQUE (agency_id, settlement_month)
);
```
