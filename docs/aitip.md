# aitip 상용 하드웨어 아키텍처 및 시스템 기획 총괄 보고서

### **1. 프로젝트 개요 및 기획 배경**

#### **1.1. 기획 목적**
* 본 문서는 기존 라즈베리 파이 기반의 소프트웨어 기능 검증(PoC) 단계를 종료하고, **실제 가맹점(식당/매장)에 대량 보급 가능한 상용 등급(Commercial Grade) 전용 임베디드 단말기 하드웨어 및 시스템 통신 구조**를 정의하기 위해 작성되었다.
* 복잡하고 고가인 윈도우 기반 POS나 단순 수신만 가능한 기존 결제 단말기 생태계의 한계를 극복하고, "전화 ARS 자동응답 + 클라우드 실시간 제어(MQTT) + 외장 영수증 인쇄"를 초저가·고신뢰성 단독 기기로 구현하는 것을 핵심 목표로 한다.

#### **1.2. 전화 회선 호환성 핵심 철학: "구리선(PSTN)이든 인터넷전화(VoIP)든 100% 무설정 올인원 지원"**
* **현실의 벽 극복:** 과거 통신사 SIP 소프트웨어 연동 방식(계정 비공개, NAT 묵음 현상, 동시 등록 불가)의 실패를 교훈 삼아, aitip은 하드웨어 물리 계층(Physical Layer) 기반의 '투 트랙(Two-Track) 인터페이스'를 내장한다.
* **완벽한 범용성 (2가지 물리 포트 동시 내장):**
  1. 옛날 **구리선 일반 국선(PSTN)** 및 **통신사 모뎀 Phone 단자(RJ-11 듀얼 잭)**
  2. 통신 3사(KT/LGU+/SKB)의 **순수 인터넷 키폰(VoIP, 수화기 RJ-9 듀얼 잭)**
* 위 두 가지 환경 모두를 단일 보드로 수용하여, **전국 99.9% 매장에 통신사나 키폰 기종 불문 10초 만에 플러그 앤 플레이(Plug & Play)로 설치**할 수 있도록 설계한다.

#### **1.3. 기존 시장(POS 및 단말기)의 구조적 한계와 차별화 포인트**
* **기존 POS사의 레거시 종속:** 기존 POS는 15~20년 전 윈도우(Windows) 기반으로 개발되어 고비용 PC 하드웨어(50~80만 원대)에 묶여 있으며, 전화(ARS) 제어 회로를 기판에 내장하지 못해 외장 USB CID 젠더를 주렁주렁 매다는 땜질식 구성을 유지해 왔다.
* **대리점(총판) 출장 유지보수 구조:** 가맹점 메뉴 수정이나 설정 변경 시 대리점이 직접 방문하여 출장비를 수취하는 구조로 인해, 클라우드 기반 100% 원격 설정 관리(MQTT Retained Config) 하드웨어를 개발할 동기가 없었다.
* **aitip의 포지셔닝:** 10만 원 미만의 초경량 임베디드 전용 보드(SoC + eMMC)를 통해 **가맹점 무방문 원격 관리, 택배 배송 즉시 설치, 강제 전원 차단 무결성**을 확보하여 독점적 시장 경쟁력을 창출한다.

### **2. 핵심 통신 프로토콜 및 네트워크 아키텍처**

#### **2.1. 폴링(Polling) / Keep-Alive / MQTT 기술 비교 및 선정 이유**

| 항목 | 일반 폴링 (Polling) | 하트비트 (Keep-Alive TCP) | 발행-구독 (MQTT, 최종 채택) |
| :--- | :--- | :--- | :--- |
| **작동 원리** | 클라이언트가 주기적으로 "주문 있냐"고 HTTP 요청 | 단일 TCP 세션을 맺고 무의미한 핑(Ping) 패킷으로 유지 | 브로커에 1회 세션 연결 후 이벤트 발생 시에만 즉각 데이터 푸시 |
| **NAT/공유기 통과** | 내부에서 외부로 요청하므로 통과 가능 | 내부에서 외부로 맺은 세션 유지 | **완벽 지원 (클라이언트 Outbound 연결 활용)** |
| **네트워크/서버 부하** | 극심한 오버헤드 (연결 생성/종료 반복) | 세션은 유지되나 1:1 연결 관리 부하 존재 | **최소화 (경량 헤더 2Byte, 저전력/저대역폭)** |
| **전송 신뢰성 (QoS)** | 유실 시 재요청 전까지 모름 | 연결 단절 시 주문 유실 위험 | **QoS 1/2 지원 (오프라인 복구 시 메시지 보장)** |

#### **2.2. MQTT 브로커 푸시 메커니즘과 UPnP 무관성**
* **브로커의 푸시 동작:** 단말기가 부팅 시 브로커에 접속하여 `aitip/orders/{가맹점ID}` 토픽을 구독(Subscribe)하면 통신 통로가 열린다. 고객 주문 인입 시 클라우드 서버가 해당 토픽으로 발행(Publish)하면, 브로커는 **이미 열려 있는 세션 통로를 타고 단말기로 즉시 밀어 넣는다(Push).**
* **UPnP/포트포워딩 불필요:** 외부에서 내부 단말기로 새로운 연결을 생성하는 Inbound 통신이 아니라, **단말기가 내부에서 외부 브로커로 먼저 뻗어나간 Outbound 세션을 재사용**하므로 공유기 설정(UPnP, 포트포워딩)이 전혀 필요 없다.

#### **2.3. 클라우드 기반 가맹점 원격 설정 (Remote Configuration)**
* **양방향 통신 활용:** 중앙 어드민 웹/노트북에서 가맹점의 설정을 변경하면 MQTT를 통해 0.1초 만에 단말기로 꽂아 넣는다.
  * 토픽 규격: `aitip/device/{가맹점ID}/config`
  * 원격 제어 항목: ARS 사용 여부, 음성 멘트 볼륨, 인쇄 매수(주방용/고객용), 인쇄 농도, 펌웨어 재부팅(Reboot), OTA 업데이트 트리거.
* **Retained Message(보관 메시지) 필수 적용:**
  * 점주가 단말기 전원을 꺼둔 상태에서 설정을 변경하더라도, 브로커에 `Retain = True`로 저장되어 단말기가 전원을 켜고 브로커에 재접속하는 순간 최신 설정값을 자동으로 동기화한다.

### **3. 프로토타입(라즈베리 파이)의 한계와 전용 PCB 전환 이유**

1. **강제 급전 차단 시 MicroSD 파일시스템 파손:** 식당 환경 특성상 매일 마감 시 콘센트를 그냥 뽑거나 멀티탭 스위치를 내린다. MicroSD 기반 보드는 쓰기 작업 중단 시 파일시스템이 100% 손상되어 부팅 불가(벽돌) 상태가 된다.
2. **외장 인쇄 시 전압 강하 (Brown-out Reset):** 영수증 프린터의 모터/열선 구동 시 수 암페어(A)의 피크 전류가 발생하며, 이는 5V USB 기반 범용 보드의 전압을 출렁이게 만들어 기기 강제 재부팅을 유발한다.
3. **제조 원가(BOM) 폭망:** 라즈베리 파이 보드 단품만 6~10만 원대로, 케이스·전원·인터페이스를 더하면 단말기 원가가 15만 원을 초과한다.
4. **KC 전파 인증(EMI) 불가:** 교육용 보드에 여러 케이블을 주렁주렁 연결한 구조는 방사 전자파 기준치를 초과하여 합법적 판매 인증 취득이 불가능하다.

#### **4.2. 세부 하드웨어 블록 설계 명세**

##### **① ARS 및 전화 제어 인터페이스 (구리선 PSTN & 인터넷전화 VoIP 듀얼 대응)**

aitip 단말기는 가맹점의 전화 환경에 구애받지 않고 100% 무설정 연동을 실현하기 위해 **2가지 물리적 연결 포트(총 4개 소켓)**를 단일 보드에 모두 탑재한다:

* **[방식 1] 일반 구리선 국선(PSTN) 및 통신사 CPG 모뎀용 RJ-11 포트**
  * **물리 커넥터:** RJ-11 6P2C/6P4C 암놈(Female) 소켓 2개 (`LINE IN`, `PHONE OUT`).
  * **회로 구성:** Silicon Labs Si3050급 DAA 절연 회로, 고전압 Ring 감지 회로, PhotoMOS 반도체 릴레이 기반 전자식 오프훅(Off-hook) 제어.
  * **보호 회로:** 전화선 직격뢰/유도뢰 차단용 가스방전관(GDT) 및 PTC 서미스터 필수 실장.

* **[방식 2] 순수 인터넷 키폰(VoIP) 직결 - 수화기(Handset) 브릿지 포트 (신규 표준)**
  * **물리 커넥터:** **RJ-9 (4P4C) 암놈(Female) 소켓 2개 기판 실장**
    * **`PHONE HANDSET IN`:** 점주가 원래 쓰던 들고 통화하는 '수화기' 선 직결.
    * **`PHONE BASE OUT`:** 동봉된 20~30cm 짧은 RJ-9 패치 케이블로 '키폰 본체 수화기 단자' 직결.
  * **10초 무도구 설치 플로우:**
    ```
    [기존 IP 키폰 본체] 
           │ (1단계: 원래 꽂혀 있던 꼬불꼬불한 수화기 선을 본체에서 쏙 뽑음)
           ▼
    [aitip 단말기]
      ├─ [PHONE HANDSET IN] ── <원래 뽑은 수화기 선>을 여기에 딸깍 꽂음
      └─ [PHONE BASE OUT]   ── <동봉된 짧은 RJ-9 선>으로 키폰 본체 수화기 단자에 딸깍 꽂음
    ```
  * **작동 메커니즘 (수화기 4선 신호 분리 제어):**
    * 수화기 4선(1·2번: 스피커 라인, 3·4번: 마이크 라인)을 고속 아날로그 멀티플렉서(Analog MUX) 또는 신호용 미니 릴레이가 중계.
    * **평상시/정전 시 (무전원 바이패스):** 단말기 전원이 꺼져 있거나 ARS 미사용 시, Normally-Closed(NC) 접점으로 본체와 수화기가 1:1 직결되어 일반 전화 통화에 0.1%의 지장도 없음.
    * **ARS 작동 시:** 전화 벨 인입 시 내부 스위치가 단말기 오디오 회로로 전환.
      * **마이크 라인(3,4번):** aitip 오디오 DAC가 키폰 본체로 "알림톡 주문은 1번을 누르세요" 음성 신호를 전기적으로 주입.
      * **스피커 라인(1,2번):** 고객이 누른 1번 톤(DTMF 신호)을 하드웨어 디코더가 실시간 가로채 감지.
      * **종료:** 알림톡 발송 완료 후 스위치를 복귀시켜 전자식으로 통화 자동 종료(On-hook).
  * **장점:** 통신사 SIP 계정/암호 불필요, 공유기 NAT 묵음 현상 배제, 통신사/키폰 제조사 상관없이 전 세계 100% 호환.

* **공통 음성/신호 처리 블록:**
  * **음성 DAC 송출:** 8kHz/16kHz 안내 음성을 왜곡 없이 송출하는 저노이즈 오디오 출력단.
  * **Barge-in 지원 DTMF 감지:** 안내 음성이 송출되는 도중에도 고객의 키패드 입력을 가로채 즉각 반응하는 하드웨어 필터링 회로 탑재.

##### **② 스토리지 및 OS 무결성 설계 (eMMC)**
* **부품 선정:** 산업용 온보드 실장형 eMMC 5.1 (4GB ~ 8GB). MicroSD 슬롯 원천 배제.
* **SquashFS Read-Only 시스템:** OS 루트 파일시스템은 읽기 전용(Read-Only)으로 마운트하여 비정상 종료 시에도 OS 손상을 물리적으로 차단.
* **A/B 듀얼 뱅크 파티션:** 펌웨어 무선 업데이트(OTA) 도중 전원이 차단되더라도 이전 정상 펌웨어로 자동 복구(Fallback)되는 안전 장치 마련.

##### **③ 전원부 및 전원 강제 차단 방어 회로**
* **전원 입력:** 산업 표준 DC 12V 1.5A ~ 2A SMPS 어댑터.
* **슈퍼커패시터(EDLC):** 전원선이 강제로 뽑히는 순간 전압 감지 회로가 CPU 인터럽트를 발생시키고, 슈퍼커패시터가 약 0.5~1초간 보드 전원을 유지하여 진행 중인 ARS 통화 정리 및 임시 캐시 안전 언마운트(Sync)를 완료하도록 유예 시간 제공.

##### **④ 외장 프린터 및 저비용 고효율 확장 포트 명세**
* **외장 영수증 프린터 인터페이스:**
  * **RS-232C (DB9 또는 RJ45 시리얼):** 매장 주방용 POS 영수증 프린터 범용 표준 직결.
  * **USB 2.0 Host (Type-A, 포트 1):** 시중 저가형 USB 영수증 프린터 직결 제어.
* **전략적 가성비 확장 포트 (단가 상승 최소화, 플랫폼 확장성 극대화):**
  * **보조 USB 2.0 Host (Type-A, 포트 2):** 유선망 장애 대비 LTE 동글 백업망 및 바코드/QR 리더기 지원.
  * **3.5mm 오디오 Out 단자 (Line-Out):** 주방 소음 대응용 외장 앰프/스피커 고출력 호출음 송출 지원.
  * **기판 내부 확장 헤더 (Internal 4-Pin / UART·GPIO):** 향후 NFC 패드 등 부가 장치용 예비 포트 확보.

### **5. 개발팀 및 하드웨어 제조사 실무 협의 액션 아이템**

1. **전화 물리 인터페이스 동시 실장 (RJ-11 국선 듀얼 + RJ-9 수화기 듀얼):**
   * 보드 한쪽에 **RJ-11 소켓 2개**(Line In / Phone Out)와 **RJ-9 소켓 2개**(Base Out / Handset In)를 동시 실장.
   * 부품 단가 상승분은 소켓 2개 합산 200원 미만으로 억제하며, 점주 자가설치용 25cm 짧은 RJ-9 패치 케이블 번들링 구성 확인.
2. **수화기 인터페이스 무전원 바이패스 릴레이 검증:**
   * aitip 단말기 전원이 꺼진 상태에서도 키폰 수화기 통화가 정상 동작하는 Normally-Closed(NC) 접점 배선 확인.
3. **SoC 선정 및 캐리어 보드 방식 검토:**
   * 상용 SOM(System-on-Module)에 I/O 인터페이스 바닥판(베이스보드)만 결합하는 방식 우선 검토.
4. **확장 포트 핀맵 배분 및 단가(BOM) 통제:**
   * 듀얼 USB Host 단자 및 3.5mm 오디오 단자 실장 (추가 부품 원가 500원 미만 엄수).
5. **MQTT 토픽 및 펌웨어 프로토콜 정의:**
   * 주문 수신: `aitip/orders/{가맹점ID}`
   * 원격 설정 수신: `aitip/device/{가맹점ID}/config` (QoS 1, Retained 필수)
   * 상태 보고: `aitip/device/{가맹점ID}/status` (LWT 활용)
6. **목표 BOM 원가 통제:**
   * 메인 제어 보드 대당 양산 단가 3~4만 원대 이하 달성 여부 검증.
